# Задачи

Список задач и проектов, где у каждой задачи есть свой чат. Статические файлы, без сборки и без зависимостей в рантайме. Задачи хранятся в браузере и переживают перезагрузку, приложение ставится на телефон и работает офлайн.

Живёт на GitHub Pages: https://cucujahx-coder.github.io/CLUTCH/

## Файлы

- `index.html` — два экрана из панелей: список задач и чат задачи. Поля «Новая задача» и «Спросить Claude» — внутри своих панелей, прилипают к низу, содержимое прокручивается под ними. Чат выезжает справа налево; назад — стрелкой, Esc или свайпом вправо от левого края.
- `panels.html` — те же данные двумя панелями рядом. На телефоне чат сверху, список снизу; при фокусе на поле ввода панель с этим полем занимает всё место над клавиатурой.
- `app.js`, `app.css` — общий движок и стили для обеих оболочек. Оболочка задаёт `window.MODE` (`two` или `nav`) перед подключением скрипта.
- `Pixelizer.ttf` — пиксельный шрифт интерфейса.
- `sw.js`, `manifest.webmanifest` — офлайн и установка на домашний экран.

## Что умеет

- В строке проекта показан следующий шаг; тап по кольцу закрывает именно его. Когда шагов не остаётся, проект уходит из списка.
- Шаги проекта можно отмечать и в чате проекта.
- Долгое нажатие по строке (или правая кнопка мыши) открывает меню: срок, «сделать проектом» или «добавить шаг», удаление. Удаление подтверждается вторым нажатием.
- Название задачи правится прямо в шапке карточки. Шаг проекта вводится полем в списке шагов: Enter добавляет и оставляет поле открытым.
- Под телефон: отступы под вырез и полосу дома, высота с учётом клавиатуры, цели нажатия от 44 px, страница не резинится.
- Под названием задачи всегда видно состояние: подпись разговора или «без диалога», срок или «без срока».
- Слева от названия в списке — знак «>».
- Нажатие на «Входящие» показывает выполненные задачи, повторное — возвращает к входящим; отметку можно снять.
- Чат по задаче и проекту (ответ пока локальная заглушка — см. ниже).
- Выполнение задачи или шага — резко: хлопок петарды (звук синтезируется в браузере), белая вспышка строки задачи, текст задачи вспыхивает белым свечением и трясётся, потом строка резко схлопывается.
- Плавные анимации с отскоком: появление новых задач, шагов и реплик, меню действий, переключение на выполненные. При `prefers-reduced-motion` движение отключается.
- Тёмная тема по системной настройке, `prefers-reduced-motion`, навигация с клавиатуры.

## Запуск

Откройте `index.html` в браузере или:

```bash
npm start
```

## Тесты

```bash
npm install
npm test
```

Проверяются логика списка, кольцо проекта, чат, экранирование ввода, поведение панелей при клавиатуре, переходы между экранами, сохранение в `localStorage`, перенос данных из прежней версии и меню действий (срок, проект, шаги, удаление в два нажатия).

## Публикация

Пуш в `main` → GitHub Actions прогоняет тесты и выкладывает файлы на Pages. Сборки нет, в артефакт попадают только отдаваемые браузеру файлы — список в `.github/workflows/deploy.yml`.

## Размеры и сетка

Все размеры заданы CSS-токенами в `:root` файла `app.css` (шаг 8 px, четыре ступени типографики 12/14/16/20, зона нажатия 48 px, строка 64 px). Менять масштаб — только там.
