# Задачи

Список задач и проектов, где у каждой задачи есть свой чат. Статические файлы, без сборки и без зависимостей в рантайме. Задачи хранятся в браузере и переживают перезагрузку, приложение ставится на телефон и работает офлайн.

Живёт на GitHub Pages: https://cucujahx-coder.github.io/CLUTCH/

## Файлы

- `index.html` — две панели сразу: список и карточка задачи. На телефоне чат сверху, список снизу; при фокусе на поле ввода панель с этим полем занимает всё место над клавиатурой.
- `screens.html` — те же данные, но полноэкранными экранами с переходом: список → задача → назад (кнопка или Esc).
- `app.js`, `app.css` — общий движок и стили для обеих оболочек. Оболочка задаёт `window.MODE` (`two` или `nav`) перед подключением скрипта.
- `sw.js`, `manifest.webmanifest` — офлайн и установка на домашний экран.

## Что умеет

- В строке проекта показан следующий шаг; тап по кольцу закрывает именно его. Когда шагов не остаётся, проект уходит из списка.
- Шаги проекта можно отмечать и в чате проекта.
- Задача: срок, переименование прямо в шапке, удаление в два касания. Задачу можно превратить в проект и добавлять к нему шаги — поле ввода появляется прямо в списке шагов, Enter добавляет и остаётся открытым.
- Под телефон: отступы под вырез и полосу дома, высота с учётом клавиатуры, цели нажатия от 44 px, страница не резинится.
- Раздел «Выполненные» сворачивается; отметку можно снять.
- Чат по задаче и проекту (ответ пока локальная заглушка — см. ниже).
- Тёмная тема по системной настройке, `prefers-reduced-motion`, навигация с клавиатуры.

## Запуск

Откройте `index.html` в браузере или:

```bash
npm start
```

## Тесты

```bash
npm install
npm test
```

Проверяются логика списка, кольцо проекта, чат, экранирование ввода, поведение панелей при клавиатуре, переходы между экранами, сохранение в `localStorage`, перенос данных из прежней версии и действия над задачей (срок, проект, шаги, удаление).

## Публикация

Пуш в `main` → GitHub Actions прогоняет тесты и выкладывает файлы на Pages. Сборки нет, в артефакт попадают только отдаваемые браузеру файлы — список в `.github/workflows/deploy.yml`.

## Размеры и сетка

Все размеры заданы CSS-токенами в `:root` файла `app.css` (шаг 8 px, четыре ступени типографики 12/14/16/20, зона нажатия 48 px, строка 64 px). Менять масштаб — только там.
