# Задачи

Список задач и проектов, где у каждой задачи есть свой чат. Статические файлы, без сборки и без зависимостей в рантайме. Задачи хранятся в браузере и переживают перезагрузку, приложение ставится на телефон и работает офлайн.

Живёт на GitHub Pages: https://cucujahx-coder.github.io/CLUTCH/

## Файлы

- `index.html` — два экрана друг над другом: список задач и чат задачи. Чат выезжает справа налево; назад — стрелкой, Esc или свайпом вправо от левого края.
- `panels.html` — те же два экрана рядом; уже 760 px — снова стопкой, с тем же переходом.
- `app.js`, `app.css` — общий движок и стили для обеих оболочек. Оболочка задаёт `window.MODE` (`two` или `nav`) перед подключением скрипта.
- `Pixelizer.ttf` — пиксельный шрифт заголовков, `play-*.woff2` — основной шрифт Play.
- `sw.js`, `manifest.webmanifest` — офлайн и установка на домашний экран.
- `worker/` — воркер Cloudflare с ключом Anthropic: системный промт, описания инструментов, стриминг. На Pages не выкладывается, разворачивается отдельно — `npm run deploy:worker`.

## Что умеет

- В строке проекта показан следующий шаг; тап по кольцу закрывает именно его. Когда шагов не остаётся, проект уходит из списка.
- Шаги проекта можно отмечать и в чате проекта.
- Долгое нажатие по строке (или правая кнопка мыши) открывает выбор приоритета: «нет» и четыре ступени. Срок, проект, шаги и удаление делаются из чата.
- Название задачи правится прямо в шапке карточки. Шаг проекта вводится полем в списке шагов: Enter добавляет и оставляет поле открытым.
- Под телефон: отступы под вырез и полосу дома, высота с учётом клавиатуры, цели нажатия 44 px, страница не резинится, отклик на нажатие вибрацией — на iPhone через переключатель Safari.
- Под названием задачи всегда видно состояние: подпись разговора или «без диалога», срок или «без срока».
- Кружок внизу справа показывает выполненные задачи, повторное нажатие возвращает к входящим; отметку можно снять.
- Чат по задаче и проекту отвечает живой моделью: ответ идёт потоком, задачу можно менять прямо из разговора (переименовать, поставить срок, завести шаги, удалить), и каждое изменение отменяется карточкой в ленте.
- К сообщению можно приложить картинку или PDF, а ассистент — сохранить файл в задачу и прочитать его обратно.
- Название задачи приводится к двум словам: пишете как придётся, в списке читается с одного взгляда.
- Настройки открываются нажатием на логотип: память ассистента, расход, корзина, стирание всех данных.
- Без адреса воркера (`API` в `app.js` пуст) отвечает локальная заглушка и приложение остаётся рабочим.
- Выполнение задачи или шага — резко: хлопок петарды (звук синтезируется в браузере), белая вспышка строки задачи, текст задачи вспыхивает белым свечением и трясётся, потом строка резко схлопывается.
- Плавные анимации с отскоком: появление новых задач, шагов и реплик, выбор приоритета, переключение на выполненные. При `prefers-reduced-motion` движение отключается.
- Тёмная капсульная тема: одна на всё приложение, главное действие — светлая заливка, а не цвет. Учитываются `prefers-reduced-motion` и навигация с клавиатуры.

## Запуск

Откройте `index.html` в браузере или:

```bash
npm start
```

## Тесты

```bash
npm install
npm test
```

Проверяются логика списка, кольцо проекта, чат, экранирование ввода, клавиатура, переходы между экранами, сохранение в `localStorage`, перенос данных из прежней версии, снимок задачи для модели, инструменты с отменой, файлы, вложения, память, короткие названия и разметка ответа. Отдельно `npm run test:worker` — сборка промта, кэш-барьеры, календарь и стриминг с подменённым Anthropic.

## Публикация

Пуш в `main` → GitHub Actions прогоняет тесты и выкладывает файлы на Pages. Сборки нет, в артефакт попадают только отдаваемые браузеру файлы — список в `.github/workflows/deploy.yml`.

## Размеры и сетка

Все цвета и кривые движения заданы токенами в `:root` файла `app.css`. Геометрия капсульная: строка 68 (44 + 11×2), радиус 28, кружки 44, большая кнопка 76, зазоры 8 между строками и 16 между блоками.
